# Decodelabs_task1
Number Guessing Game (Java) A beginner-friendly console-based game built in Java where the user tries to guess a randomly generated number within a specified range. This project was created to practice core programming fundamentals like control flow, loops, and user input handling.

Features & Requirements:-

>Random Number Generation: Automatically generates a random number within a chosen range (e.g., 1 to 100) using Java utilities.

>Interactive User Input: Accepts guesses from the player via the console.

>Dynamic Feedback: Provides immediate hints ("Too high!" or "Too low!") to guide the player toward the correct answer.

>Game Loop: Continues running until the correct number is successfully guessed.

Optional Enhancements:

>Attempt limits to increase difficulty.

>Multiple rounds of gameplay.

>Final score tracking based on attempts taken.

Key Concepts Covered

>Java Random Class for number generation.

>Control Flow & Conditionals (if-else statements) for validating guesses.

>Loops (while / for) for managing the game flow and round repetitions.
>Input Handling (java.util.Scanner) for reading user console inputs safely.
